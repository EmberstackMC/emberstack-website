04 GET PLAYING

From download
to in-game.

Every project can have its own loader and version requirements. Check its release page before installing.

  1. 01

    Check the project page

    Confirm the Minecraft version, mod loader, and required dependencies.

  2. 02

    Install the matching loader

    Use the project’s listed loader and create a matching launcher profile.

  3. 03

    Download from the release page

    Use the linked Modrinth release and follow its file and installation notes.

  4. 04

    Launch and enjoy

    Start the matching profile. If something goes wrong, check the FAQ or ask in Discord.

05 QUICK ANSWERS

Good to know.

Which Minecraft versions do your projects support?+

Support varies by project. Check the project card and its linked release page for the latest supported versions.

Which mod loader should I install?+

Each project lists its required loader. Install the matching loader and make sure your launcher profile uses the same Minecraft version.

Where should I download Emberstack mods?+

Use the project’s official Modrinth release link. That page has the current files and release-specific instructions.

How do I report a bug or suggest a feature?+

Use the project’s GitHub issue tracker when available, or join the Emberstack Discord to point us in the right direction.

Can I use a project in my modpack?+

Check the license and permissions on that project’s release page before redistributing it.
